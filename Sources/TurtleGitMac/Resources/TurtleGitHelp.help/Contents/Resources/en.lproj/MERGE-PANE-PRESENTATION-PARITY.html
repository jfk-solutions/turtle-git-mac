Compare uses compact single-line pane headers with the source Removed/Added palette. Three-way Merge uses neutral headers. Each header retains its pane title and source description, prefixes a modified pane with * , and draws an active focus edge. Literal titles and full paths remain available in native tooltips; embedded tabs and line separators use visible symbols only in the bounded caption. The document, path and saved bytes are unchanged. Colors use the owning comparison's captured palette preferences and adapt to light/dark appearance.

Pressing a header focuses its actual editor. Readonly panes retain navigation and status. Closed, detached or replaced owners, busy operations and open sheets refuse activation. Captured callbacks cannot revive across Quit, reload, pane exchange or optional Base replacement. Combined one-pane Compare follows the active combined editor. Three-way Merge retains the independent result dirty indicator and existing kept-source explanation.

The status bar reports the focused pane's one-based logical UTF-16 column, matching the source caret view coordinate. A tab counts one character, a non-BMP character uses two UTF-16 units, and wrapping does not reset the logical column. Marked-word counts follow source order: L for left, R for right and B for the bottom result. A separate optional Base preview is an additional native pane; its marks do not replace the source bottom count. Changing the marked word can change counts within the same line, independently of locator row highlights. The existing View/Status Bar preference hides and restores these indicators.
