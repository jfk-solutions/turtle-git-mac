TurtleGit brings TortoiseGit’s menus, dialogs, revision history and status artwork to macOS. The goal is a complete port, with Finder integration and the same familiar workflow.

Real native windows, disposable sample data

The Log Messages window

The compact graph sits before the revision list. Select a commit to read its full message and inspect changed files, status and line counts below. Three resizable panes keep the familiar TortoiseGit arrangement.

History and comparisons

Topology-based graph, reference labels, full commit messages, changed-path statistics, search/date filters, all branches, older revisions and unified comparisons.

Familiar command icons

Original upstream artwork in app context menus and the Finder submenu. Colored icons retain their appearance; the monochrome cherry-pick glyph adapts to dark mode.

Finder integration

A Finder Sync extension provides cached repository status badges and a TurtleGit command submenu. Activation and visual checks still require a signed install.

Commit checked files, or enable the staging area

The native Commit window keeps the message above a checked file list. Checkbox mode commits current whole-file contents and preserves unchecked staged changes. Enable staging area switches to three-state checkboxes and commits the index, preserving later working-tree edits. An attached patch window stages or unstages selected lines and hunks in ordinary tracked UTF-8 text files. Advanced controls and other file types remain in progress.

Build from source

Requires macOS 13 or later, Xcode with the macOS SDK, and Git. The generated Xcode project includes the app and Finder extension.

swift test
./scripts/build.sh
open build/Build/Products/Debug/TurtleGitMac.app

Use swift run TurtleGitMac for an app-only preview. Signed Finder integration needs an Apple signing team and matching App Group configuration.
