Familiar Git workflows.
Native Mac windows.

TurtleGit brings TortoiseGit’s menus, dialogs, revision history and status artwork to macOS. The goal is a complete port, with Finder integration and the same familiar workflow.

Abort Merge with familiar reset choices

Choose Merge, Mixed or Hard in the native Abort Merge dialog. Show modified files opens an owned comparison of HEAD with the working tree. OK opens a separate Reset progress window, where Git output appears as the command runs.

If a reset fails, its Git diagnostic stays visible beside Retry and Close. Merge Retry returns to the options; Mixed and Hard Retry repeat the selected reset. Escape cancels an active command and closes progress after the process stops; it also closes a finished result. The existing confirmation setting asks Yes/No before cancellation. The selectable output offers Copy and Copy All with original icons, preserves selection when copying all, and highlights error prefixes and links after completion. A colored result footer reports success or failure, with optional elapsed time and a localized finish timestamp.

For developers and early testing

Build from source

Requires macOS 13 or later, Xcode with the macOS SDK, and Git. The generated Xcode project includes the app and Finder extension.

swift test
./scripts/build.sh
open build/Build/Products/Debug/TurtleGitMac.app

Use swift run TurtleGitMac for an app-only preview. Signed Finder integration needs an Apple signing team and matching App Group configuration.
