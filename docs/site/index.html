Git, close at hand

TurtleGit brings the workflows of TortoiseGit to macOS: Finder context menus, file status badges, commits, branches and remote synchronization.

Inspect a repository’s history, compare files and resolve conflicts with built-in tools. Native windows support light and dark appearances, with help available offline.
