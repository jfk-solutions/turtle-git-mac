## State and image placement

The renderer retains the low-byte recorded mode, validates the empty record
body, ignores reserved high flag bits, and captures immutable mode/pixel-offset
values for each draw. Save/Restore retains that state; both containers enter
default interpolation and restore their parent's state on exit. Unrecorded
default, explicit default and bilinear use the same bounded device sampler.
Recorded nearest-neighbor uses a distinct nearest kernel. Crop, wrap/reflection,
clamp color, affine placement, existing clips, alpha and ordered SourceCopy
coverage are preserved rather than delegated to an SVG image filter.

The sampler reserves destination color/coverage planes and bounded work before
allocation. A large virtual source rectangle does not expand its source bitmap
or serialize its PNG once per visible tile. The historical
`unsupported-image-tile-budget.emf` is consequently a valid positive input with
unchanged original bytes. Its independent noise-source checks are separate from
the earlier texture-brush budget contract.

Texture brushes, the final Picture consumer and vector metafile children retain
their separate playback contracts. Existing spatial effects retain their
measured bilinear placement; a recorded nearest choice changes placement after
the effect, without changing the effect's source pixels. Cubic and prefiltered
modes `2/4/6/7` remain explicitly unsupported for bitmap paint. They must not
silently return a successful approximation or earlier partial paint. Pointwise
effects retain preparation before their color operation. Device filtering and
the output/Picture consumer provide the two measured result-association stages;
those lossy stages are no longer also baked into the effect PNG. Plain bitmap
pixels enter sampling directly. Existing full effect references and tolerances
are unchanged.

## Independent Windows observations

Microsoft's [interpolation enumeration](https://learn.microsoft.com/en-us/openspecs/windows_protocols/ms-emfplus/51312252-755a-4c8b-84bd-6ae73da1b5ea)
defines the serialized algorithms. Native GDI+ file playback supplies an
additional compatibility observation: raw wire mode `1` is identical to
`0/3` bilinear on the observed Windows11 ARM64 runtime, despite the protocol's
stated nearest alias. Mode `5` produces nearest-neighbor. The independent witness
changes only that low flag byte in native files, retaining whole natural/Picture
RGBA observations rather than inferring serialization from an API getter.

For default/None, recorded nearest draws select `floor(q + .5)` after mapping an
integer destination point into the original wire source rectangle. Recorded
Half additionally locates the destination center at `+.5`, then subtracts `.5`
from the mapped source position. Any source-rectangle adjustment already written
by the Windows recorder remains part of the wire and is not removed. Device
scanline coverage is a separate operation; source-coordinate inclusion alone
does not reproduce reflected and affine boundary pixels.

The original witness source, environment/identity metadata, raw files and phase
analysis are in `qa/metafile-interpolation-reference-2026-11-05/`. They are native
Windows observations, not images generated by TurtleGit. The initial Half-affine
differences identify a distinct nearest arithmetic profile: Float32 row starts
and additions round to nearest; inverse increments truncate toward zero; source
phase subtraction and the nearest tie addition each retain Float32 rounding.
That independent model matches all 48 nearest opaque/alpha reference scenes.
The native Core check compares complete Picture RGBA for all 304 imported cases,
including a varied-color/alpha atlas that exposes normalization losses hidden by
pure primaries. Direct Metafile and file-backed Picture pixels remain separate
unchanged reference files. The measured 96-DPI and screen-HDC recording setups
produced identical native bytes; natural canvas sizing uses the recorded physical
frame/device DPI without editing headers or padding expected images. This does not
claim arbitrary interpolation kernels, every encoder or exhaustive GDI+ identity.
